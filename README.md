FitHub - Advanced demo project skeleton (backend + frontend)
This ZIP contains a runnable Flask backend skeleton and a React frontend skeleton.
Backend:
  - cd backend
  - python3 -m venv venv
  - source venv/bin/activate
  - pip install -r requirements.txt
  - python app.py
Frontend:
  - cd frontend
  - npm install
  - npm start
Notes:
- Avatar generator and summarizer are placeholders to avoid heavy model downloads.
- For full advanced features (Stable Diffusion, embeddings, FAISS), add the required models and tokens.
