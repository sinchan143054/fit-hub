# FitHub

FitHub is a fitness and wellness web application developed to help users manage workouts, health activities, and personalized fitness recommendations through an interactive platform.

## Features

- User authentication and login system
- Personalized workout recommendations
- Fitness and wellness dashboard
- Responsive user interface
- Flask backend with React frontend

## Tech Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite / MySQL

## Implementation

FitHub is developed using a full-stack architecture where the React frontend provides an interactive and responsive user interface, while the Flask backend handles authentication, fitness management, and application logic.

- Implemented secure user authentication and login system
- Developed personalized workout recommendation functionality
- Integrated backend APIs with frontend components
- Designed responsive fitness dashboard for tracking activities
- Connected database for storing user and fitness-related data

## How to Run the Project

### Backend Setup

```bash
cd backend
python -m venv venv
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

Open browser and run:

```bash
http://localhost:3000
```
