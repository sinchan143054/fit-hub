# FitHub

FitHub is a fitness and wellness web application developed to help users manage workouts, health activities, and personalized fitness recommendations through an interactive platform.

## Features

- User authentication and login system
- Personalized workout recommendations
- Fitness and wellness dashboard
- Responsive user interface
- Flask backend with React frontend

## Tech Stack

Frontend:
- React.js
- HTML
- CSS
- JavaScript

Backend:
- Python
- Flask

Database:
- SQLite / MySQL

## Installation

Backend Setup

```bash
cd backend
python -m venv venv
pip install -r requirements.txt
python app.py
```

Frontend Setup

```bash
cd frontend
npm install
npm start
```
